# 支教知识视频工坊

DSH 插件：把一段台本变成可逐帧可视化编辑的代码讲解视频，并导出 1080p30 的 mp4。

## 它做什么

- **左侧栏入口**「支教知识视频工坊」→ 中央面板打开整页编辑器，不刷新页面、不改动会话区。
- **台本 → 初稿**：粘贴文本，或导入 `.md` / `.txt` / `.docx` / `.xlsx` / `.pdf`，交给已配置的大模型生成分镜初稿（场景数组 + 字幕），落盘成可继续编辑的工程文件。
- **可视化编辑**：文字内容、字体家族/字号/行距/对齐、文字色与强调色、背景（纯色/渐变）、代码块语言 + 高亮 + 行号、字幕（文本/起止时间/字号/颜色/底衬/位置）。
- **时间轴**：场景重排、改时长、加转场；字幕轨单独成轨。
- **音频**：旁白 + BGM 挂到工程上，导出时自动混音。
- **导出**：浏览器 canvas 逐帧渲染 → 上传到本机 ffmpeg → H.264 / 1920×1080 / 30fps / tv range，同时导出 `.srt` 字幕。

预览和导出走**同一个渲染器**（`drawFrame`），所见即所得。

## 用法

1. 点左侧栏「支教知识视频工坊」。
2. 「＋ 新建」建工程，或「台本 → 初稿」从台本生成初稿。
3. 左侧选场景 → 中间看画布 → 右侧四个 tab（场景 / 外观 / 字幕 / 音频）改内容与样式。
4. 底部时间轴调时序、改时长、加转场。
5. 「导出 MP4」。

工程存在 `<当前会话目录>/video-projects/<工程名>/`：

```
project.json        工程数据（scenes / look / subtitles / audio / timeline）
assets/             上传的音频、图片
exports/            导出的 mp4 与 srt
```

## 依赖

- **ffmpeg**：导出必需，需在 PATH 里。面板打开时会探测，缺失会提示。
- **Python + pymupdf**：只有导入 PDF 台本时需要；会依次尝试 `VIDEO_WORKSHOP_PYTHON` 环境变量、`python`、`py`、`python3`。
- **大模型**：只有「台本 → 初稿」与 AI 改写/翻译需要，用 DSH 里已配置的 provider。模型调用失败会自动降级为按句切分的粗略初稿（结果里带 `warning`）。

## 已知限制

- 改 `client.js`（前端）后需要**刷新页面或重启 DSH** 才生效；改 `lib/*.js`（宿主）后需要用插件管理器 disable / enable 一次。
- 当前只做「场景工程」的可视化编辑，不会去改已有 mp4 画面里的像素字；mp4 只能作为素材叠加。
- 单条视频建议 ≤3 分钟；画布尺寸、帧率、场景数都是参数，改成竖屏或 4K 只是改工程里的 `canvas` 字段。
- 同一场景区间内画面是静态的（本渲染器没有逐帧动画），导出时按「场景 + 当前字幕」复用 JPEG，因此导出速度主要花在上传和 ffmpeg 编码上。

## 开发

```bash
node test/smoke.mjs        # 17 项：路由、CRUD、乐观锁、路径安全、帧接口边界
node test/e2e-render.mjs   # 13 项：真跑 ffmpeg，验证编码、混音、字幕、清理
```

宿主侧结构：

| 文件 | 职责 |
| --- | --- |
| `index.js` | 插件入口，注册 `/video-workshop/api` HTTP 路由 |
| `lib/api.js` | 全部 HTTP 端点分发 |
| `lib/store.js` | 工程读写、`look` 归一化、rev 乐观锁、路径安全 |
| `lib/script-parse.js` | md/txt/docx/xlsx 解析（零依赖读 ZIP），pdf 走 Python |
| `lib/ai.js` | 模型列表、台本→分镜、文字改写 |
| `lib/render.js` | 帧接收、ffmpeg 参数组装、混音、清理 |
| `lib/media.js` | Range 文件流、ffprobe、子进程 |
| `client.js` | 整个编辑器 UI 与 canvas 渲染器 |
